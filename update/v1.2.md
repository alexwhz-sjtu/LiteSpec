1. DLite transition 复用 RNN/head logits
- KL 和 supervised loss 共用一次 student head，投影次数 2→1。
- 已验证梯度一致。

2. DFlash/DFlash2 日志复用 draft logits
- 指标直接使用 objective 的 logits，删除日志步骤额外的词表投影。
- 带指标的前向，每个 chunk 投影 2→1。

3. checkpoint 重算时跳过日志回调
- backward 不再重复计算日志中的投影和指标，包括仅用于日志的 teacher 投影。
- 训练 objective 所需的重算仍保留。

4. DSpark 复用分布诊断结果
- 接受概率、L1 距离、teacher/student top-1 概率复用已有结果，减少重复 softmax 和归约。

5. FP32 master→BF16 参数直接拷贝
- 更新和恢复时使用 copy_(master)，去掉“先生成完整 BF16 临时张量，再拷贝”的过程。
- 减少临时分配和内存搬运。

6. L1 后续运算编译融合
- 保留原生 softmax，融合差值、绝对值、加权和归约；CE 现在保持原生。
- 最新稳定训练观察：
  - loss 阶段：24.68→22.86ms，耗时降低 7.4%
  - backward：71.71→70.09ms，耗时降低 2.25%
  - allocated 峰值：28.70→26.67GiB，减少 2.03GiB

7. KL 编译与 teacher 计算边界优化
- teacher 概率提前计算并 detach，避免 AOT 自身 backward 重算 teacher normalization。
- 历史独占 GPU 算子微基准，shape [512,151936]：
  - FP32：2.661→1.643ms，耗时降低 38.3%
  - BF16：3.297→1.705ms，耗时降低 48.3%

8. BCE 编译及小输入回退
- 适用的 FP32-target BCE 允许编译；CPU、小输入的 auto 路径保留原生。
- 公共 loss 使用大小门槛，避免小 workload 盲目编译。
